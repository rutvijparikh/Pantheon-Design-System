Pantheon Copilot

Audits any page against the Pantheon design tokens, then asks Claude what is worth fixing.

Anthropic API key

Stored with chrome.storage.local on this machine only — never synced to your Google account, and sent only to api.anthropic.com. Create one at console.anthropic.com.

Model

How hard Claude works on each review. Higher levels think longer and cost more.

Token source

The extension ships a copy of sample-tokens.json from this repository. Point it somewhere else to audit against a different token set.

Needs site access for that host, which the panel will ask for the first time it fetches.

Site access

Pantheon Copilot reads a page only after you grant access to that site, and only when you ask it to. Page content is sent to the Anthropic API as part of the audit.
